# Inclusive Content & Bias Auditor for Agents

Audit AI agent outputs for demographic representation, inclusive language, and unintended bias. Detects gendered language, racial stereotyping, ageist assumptions, and ableist phrasing. Generates bias heatmaps across agent outputs, tracks improvement over time, and provides alternative phrasings. Research: 74% of consumers prefer brands that demonstrate inclusive values — biased agent outputs cause reputational damage at scale (Edelman Trust Barometer 2026).

## Platform Compatibility
Works with Claude Code, Cursor, Codex CLI, OpenClaw, GitHub Copilot, and all SKILL.md-compatible agents.
