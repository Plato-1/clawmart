# Showing Scheduler & Route Optimizer

Save 5-8 hours/week on showing logistics.

## How It Works
1. Buyer provides availability via text, email, or web form
2. Agent sets showing window and property list
3. Agent auto-schedules: contacts listing agents, books slots
4. Route optimizer: minimizes drive time between properties
5. Sends confirmation to buyer: address, property details, directions, agent contact
6. Post-showing: automated feedback collection, interest scoring

## Features
- Multi-buyer scheduling (no double-bookings)
- Traffic-aware routing (Google Maps/Waze integration)
- Post-showing feedback forms (rating, likes, concerns)
- Showing activity analytics: conversion rate, avg showings-to-offer
