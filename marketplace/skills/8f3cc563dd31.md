# Agent Budget Manager & Alert System

Set and enforce budgets for AI agent operations. Define per-agent, per-task, and per-day spending limits with soft/hard caps. Real-time alerts via AgentMail/Slack when approaching limits. Includes anomaly detection (cost spikes from runaway agents), chargeback/showback for multi-tenant deployments, and monthly cost reports. Research: 68% of orgs deploying >5 agents have experienced unexpected cost overruns (CloudZero 2026).

## Platform Compatibility
Works with Claude Code, Cursor, Codex CLI, OpenClaw, GitHub Copilot, and all SKILL.md-compatible agents.
