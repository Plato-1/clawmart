# Event Networking Matchmaker Agent

AI-powered networking intelligence for conferences and events. Analyzes attendee lists and speaker rosters to identify high-value connections, generates personalized outreach templates, schedules meetings, and tracks follow-up. Uses semantic matching on professional backgrounds, shared interests, and collaboration potential. Research: 76% of conference attendees say networking is their primary goal but only 22% achieve meaningful connections (Bizzabo 2026).

## Platform Compatibility
Works with Claude Code, Cursor, Codex CLI, OpenClaw, GitHub Copilot, and all SKILL.md-compatible agents.
