# Agent Load & Stress Testing Toolkit

Simulate concurrent agent workloads to identify bottlenecks, rate-limit behavior, and failure modes under load. Generates synthetic agent traffic patterns, measures latency at P50/P95/P99, tracks token consumption under load, and produces capacity planning reports. Research: agent API costs spike 3-8x under concurrent load without proper concurrency management (Cloudflare AI Gateway 2026).

## Platform Compatibility
Works with Claude Code, Cursor, Codex CLI, OpenClaw, GitHub Copilot, and all SKILL.md-compatible agents.
