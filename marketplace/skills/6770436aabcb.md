# Agent Token Cost Tracker & Optimizer

Real-time per-task token cost tracking across all major LLM providers (OpenAI, Anthropic, Google, DeepSeek, Groq, Together). Tracks input/output tokens, caches costs, identifies waste patterns (redundant context, oversized prompts), and suggests optimization strategies. Research: average agent wastes 23-41% of tokens on redundant context — optimization saves $500-2,000/month per production agent.

## Platform Compatibility
Works with Claude Code, Cursor, Codex CLI, OpenClaw, GitHub Copilot, and all SKILL.md-compatible agents.
