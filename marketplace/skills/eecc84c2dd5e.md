# Comparative Market Analysis (CMA) Agent

60 seconds. Professional CMA. Branded delivery.

## What It Generates
- Recommended list price with confidence interval (+/- 3%)
- Active listings comparison (price, days on market, price/sqft)
- Pending sales analysis (market direction indicator)
- Sold comps (last 3-6 months, 0.5-mile radius adjustable)
- Price-per-square-foot trends (30/60/90 day)
- Absorption rate + months of inventory
- Market velocity: how fast homes are selling

## Features
- Automated adjustment calculations (bedrooms, bathrooms, sqft, condition, lot, garage)
- Comparable selection justification (why each comp was chosen)
- Listing presentation mode (client-facing, branded)
- Export: branded PDF, shareable link, MLS-formatted

## Data Sources
- MLS (200+ boards via RESO API)
- Public records (tax assessor, deed transfers)
- Market data (Zillow, Redfin, Realtor.com aggregates)
