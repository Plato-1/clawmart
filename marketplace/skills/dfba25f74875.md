# Student Progress Analytics Agent

Identify at-risk students 4-6 weeks earlier. Actionable insights from gradebook data.

## Analytics Modules
- Grade trend analysis: individual, class, grade-level
- Assignment completion patterns: who's falling behind?
- Assessment item analysis: which questions/concepts are most missed?
- Learning gap identification: standard-by-standard
- At-risk early warning: attendance + grades + engagement
- Intervention effectiveness tracking: did the extra help work?

## Outputs
- Teacher dashboards (per class, per student)
- Administrator dashboards (school-wide, grade-level comparisons)
- Parent reports: progress snapshots, intervention alerts
- Standards-based grading conversion

## Features
- FERPA compliant
- LMS integration: Canvas, Google Classroom, Schoology, Blackboard
- SIS integration: PowerSchool, Infinite Campus, Skyward
