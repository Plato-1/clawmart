# Investment Property Analyzer Agent

30-second investment analysis. Used by investors managing $200M+.

## Metrics Calculated
- Cap rate (purchase and pro-forma)
- Cash-on-cash return (year 1 and stabilized)
- IRR projection (5-year hold, 3 scenarios)
- DSCR (debt service coverage ratio)
- GRM (gross rent multiplier)
- Break-even occupancy rate
- 50% rule check
- 1% rule check

## Data Sources
- Rent comps: Zillow, Rentometer, local MLS
- Tax records: county assessor
- Insurance: estimated via CLUE reports
- Maintenance: age-adjusted projections

## Scenarios
- Conservative, base, optimistic modeling
- BRRRR calculator (Buy, Rehab, Rent, Refinance, Repeat)
- 1031 exchange analysis
