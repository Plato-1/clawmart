# Viral Thumbnail Designer Agent

AI thumbnails that learn from your niche. 2-4% CTR improvement.

## How It Works
1. Agent analyzes top-performing thumbnails in your niche
2. Generates 5+ concepts per video (different styles, emotions, layouts)
3. A/B tests automatically via YouTube's thumbnail testing
4. Iteratively improves based on CTR data

## Design Elements
- Face expression optimization: surprise, curiosity, excitement, confusion
- Text overlay: optimal font, color, size, placement per niche
- Background: color psychology, contrast, pattern interruption
- Mobile-first: 60%+ of YouTube views are mobile

## Integration
- YouTube Analytics (CTR tracking)
- Canva API (export/remix)
- Photoshop template export
