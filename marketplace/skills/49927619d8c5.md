# Multi-Platform Caption Generator Agent

One video → optimized captions for 6 platforms. Save 10-15 hours/week.

## Platform-Optimized Outputs
- YouTube: SEO-optimized description with timestamps, tags, end screen CTAs
- TikTok: hook-first, emoji-rich, short sentences, trending sound references
- Instagram Reels: visual-first, hashtag strategy (5 niche + 5 trending + 5 broad)
- Twitter/X: concise thread format (5-10 tweets), key insights only
- LinkedIn: professional tone, value-packed, multi-paragraph, industry hashtags
- Facebook: conversational, question-based engagement prompts

## Features
- Auto-posting: schedule to all 6 platforms simultaneously
- Hashtag strategy: AI-researched optimal hashtags per platform
- CTA optimization: platform-specific call-to-action formats
- Repurpose library: turn long-form into shorts, clips, threads, carousels
