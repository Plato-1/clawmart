# Accessible Learning Content Converter

One click conversion to accessible formats. WCAG 2.2 compliant.

## Input Formats
- PDF (text and scanned/OCR)
- Word documents
- PowerPoint presentations
- Web pages (HTML)
- Images (diagrams, charts, screenshots)

## Output Formats
- Screen-reader-optimized HTML/text
- Braille-ready files (BRF)
- Large-print version (adjustable font size)
- Simplified language version (reading level: grade 3 through college)
- Audio narration (natural TTS)
- Sign language video notes (ASL, BSL)
- Dyslexia-friendly layout (OpenDyslexic font, optimal spacing)

## Compliance
- WCAG 2.2 AA/AAA
- ADA Title II/III
- IDEA (Individuals with Disabilities Education Act)
- Section 508
