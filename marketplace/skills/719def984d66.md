# HIPAA-Compliant Patient Intake Agent

Automate patient intake while maintaining HIPAA compliance.

## Features
- Customizable digital intake forms
- Real-time insurance eligibility verification
- PHI encryption at rest + in transit
- Complete audit trail for compliance
- Automatic chart prep (CCD/FHIR formats)
- Multi-language support (12 languages)
- Accessibility compliant (WCAG 2.1 AA)

## Integrations
- EHR systems: Epic, Cerner, Athenahealth, eClinicalWorks
- Insurance verification: Change Healthcare, Availity, PokitDok
- Calendar: Google Calendar, Microsoft Outlook
- SMS/Email reminders for appointments

## Compliance
- HIPAA Security Rule (encryption, access controls)
- HIPAA Privacy Rule (minimum necessary access)
- Business Associate Agreement (BAA) ready
- SOC 2 Type II aligned
