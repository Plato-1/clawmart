# Academic Integrity Monitor Agent

AI-generated work detection. 7 models. 120+ institutions.

## Detection Capabilities
- AI generation probability score (0-100%)
- 7-model ensemble detection (reduces false positives)
- Writing style consistency analysis
- Plagiarism: web crawlers + academic databases
- Contract cheating patterns (ghostwriting service fingerprints)

## AI Models Detected
- ChatGPT (GPT-4o, GPT-4.1, o-series)
- Claude (3.5, 4, Opus)
- Gemini (1.5, 2.0)
- DeepSeek (V3, R1)
- Custom fine-tuned models (anomaly detection)

## Safeguards
- Never auto-penalizes: flags for instructor review only
- False-positive protection: ensemble consensus required
- Student appeal workflow: integrated review process
- Instructor override: manual reclassification supported
