# Agent ROI Calculator & Value Attribution

Measure the actual ROI of each AI agent in your fleet. Attributes business outcomes to specific agent actions, calculates cost-per-outcome (e.g., cost per resolved ticket, cost per qualified lead), and compares against human equivalent cost. Includes time-to-value tracking, productivity lift measurement, and ROI dashboards for stakeholders. Research: 47% of AI agent deployments can't quantify ROI — this is the #1 blocker to scaling (McKinsey 2026).

## Platform Compatibility
Works with Claude Code, Cursor, Codex CLI, OpenClaw, GitHub Copilot, and all SKILL.md-compatible agents.
