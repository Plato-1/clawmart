# Insurance Fraud Detection Agent

47 fraud indicators. 25-40% improvement in detection. $5-12M annual savings.

## Fraud Categories Detected
1. Identity fraud: synthetic IDs, identity theft, ghost applicants
2. Application fraud: material misrepresentation, premium evasion
3. Claims fraud: staged accidents, inflated damages, phantom injuries
4. Provider fraud: upcoding, unbundling, phantom services, kickbacks
5. Organized fraud: staged accident rings, provider networks, runners/cappers
6. Internal fraud: agent/broker churning, sliding, premium diversion

## Features
- Real-time scoring at FNOL (before payment is authorized)
- Social network analysis: detect organized rings across claims
- Provider billing pattern anomaly detection
- Historical claims cross-referencing (same claimant, same vehicle, same location)
- SIU (Special Investigations Unit) case management

## Integrations
Guidewire, Duck Creek, Majesco, Insurity.
