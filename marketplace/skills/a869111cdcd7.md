# Free Trial Gating Template

Convert free users to paid. Based on 2026 research: 3-10 run trials > indefinite freemium.

## Why Trial Gating Works
- Freemium burns inference costs forever with no path to revenue
- 7-day or 10-run trials show quality without indefinite cost
- Users who feel the quality convert at 15-35%
- Indefinite free users convert at <3%

## Included
- Trial gate logic: limit by runs (3/5/7/10) or days (3/5/7/14)
- Conversion messaging: soft upgrade prompt → urgency → hard gate
- Usage dashboard: show users what they've used
- A/B test framework: compare trial lengths
- Analytics: track trial-to-paid conversion rate

## Quick Setup
```python
from trial_gate import TrialGate
gate = TrialGate(user_id, max_runs=5, trial_days=7)
if gate.is_expired():
    return {"error": "Trial expired. Upgrade →"}
```
