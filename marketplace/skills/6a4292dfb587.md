# Property Listing Auto-Writer Agent

One click. Multiple platforms. SEO-optimized. Compliance-checked.

## How It Works
1. Upload property photos (interior, exterior, amenities)
2. Agent extracts features via vision AI: room types, finishes, views, upgrades
3. Integrates property data: square footage, bedrooms, bathrooms, lot size, year built
4. Generates unique, compelling listing descriptions
5. Publishes to MLS, Zillow, Realtor.com, Redfin, Trulia, and 10+ platforms

## Features
- Room-by-room feature extraction from photos
- Neighborhood highlights (schools, transit, amenities)
- Fair Housing Act compliance check
- SEO keyword optimization for each platform
- A/B testing: generate 3 variants, track which converts
