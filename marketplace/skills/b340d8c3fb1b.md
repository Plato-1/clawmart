# Agent Performance Dashboard — Fleet-Wide KPI Monitoring

Real-time performance dashboard for AI agent fleets. Tracks per-agent and aggregate KPIs: throughput (tasks/hour), accuracy rate, cost-per-task, latency (p50/p95/p99), error rate, hallucination frequency, user satisfaction proxy, and ROI. Includes: agent leaderboard, trend analysis (week-over-week), anomaly detection (statistical outliers), SLA compliance tracking, and exportable reports (PDF/CSV). Research: 'Usage dashboards reduce churn — users pay more when they see what they consume' (Lago 2026).
