# AgentCash Pay-Per-Call API Wrapper

Wrap any MCP tool or REST API with AgentCash pay-per-call billing. Each API call = micro-payment in USDC. No monthly subscriptions. No KYC. Agents pay agents automatically. Implements x402 HTTP payment protocol. Includes: rate limiting, usage metering, payment verification, revenue analytics. Based on Nevermined's dynamic pricing pattern. Micro-transactions from $0.001.
