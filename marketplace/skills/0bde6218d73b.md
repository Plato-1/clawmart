# Agent Model Selection & Right-Sizing Advisor

Automatically select the right model for each agent task based on complexity, cost, and quality requirements. Analyzes task characteristics (reasoning depth, context length, latency sensitivity) and recommends the optimal model-tier mix — use GPT-4 for complex reasoning, Claude Haiku for classification, Gemini Flash for multimodal. Includes automatic model downgrade when quality thresholds are met. Research: right-sizing models reduces costs 30-50% with negligible quality impact (Anthropic model selection guide 2026).

## Platform Compatibility
Works with Claude Code, Cursor, Codex CLI, OpenClaw, GitHub Copilot, and all SKILL.md-compatible agents.
