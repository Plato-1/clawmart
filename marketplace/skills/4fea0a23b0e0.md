# x402 Monetization Gateway Kit
## Charge AI agents per API call with Cloudflare's x402

Complete implementation guide for x402 protocol:
- Cloudflare gateway setup
- HTTP 402 payment required flow
- Stablecoin payment integration
- Per-call metering and billing
- API endpoint protection

Cloudflare launched x402 Monetization Gateway in June 2026. The x402 HTTP payment protocol enables AI agents to pay for APIs and services using stablecoins.
